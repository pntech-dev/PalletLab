# Матрица приёмки миграции

Этот документ фиксирует обязательный функциональный паритет между текущей
версией на PyQt5/PyVista и будущей версией на React/pywebview/Three.js. Пункт
считается перенесённым только после автоматической проверки там, где она
возможна, и ручной проверки на Windows для интерактивных либо CAD-сценариев.

## Baseline

Зафиксировано на ветке `feat/web-migration` до переноса application layer:

| Проверка | Результат | Ограничение |
| --- | --- | --- |
| `pytest -q --ignore=tests/test_step_model.py` | 157 passed | Пройдено локально. |
| `tests/test_step_model.py` | Не запущен | В `.venv` отсутствует `cadquery-ocp` (`OCP`); повторная загрузка 46 МБ wheel не завершилась. |
| Настоящие CAD-экспорты | Не запущены | Требуют установленные SolidWorks/КОМПАС-3D и ручную проверку результата. |
| OpenGL/PyVista interaction | Не запущен | Требует интерактивный Windows desktop. |

Непройденные пункты baseline нельзя считать регрессией исходного кода. Их нужно
выполнить в корректно подготовленном Windows окружении до удаления старого
пути либо при финальной приёмке нового viewport.

## Правило финальной приёмки

Удаление PyQt5/PyVista и выпуск новой версии разрешены только когда все строки
этой матрицы имеют подтверждённый результат. Новый Figma-дизайн проверяется
повторным проходом той же матрицы: визуальные изменения не отменяют ни одного
функционального требования.
