# PalletLab

PalletLab — Windows-приложение для проектирования многослойных деревянных поддонов под оборудование. Оно рассчитывает размещение брусьев, показывает результат в 3D, умеет строить поддон по STEP-модели установки и экспортирует его в CAD.

## Что изменилось в 0.4.0-beta

- Добавлен режим **«Изменить сечение»**: выбор одного или нескольких брусьев в 3D-виде, стандартное или собственное сечение, проверка геометрии, выравнивание слоёв, корректные размеры и сохранение в проекте.
- Добавлена многослойная конструкция: добавление, удаление и перестановка слоёв, автоматическое чередование направлений и синхронизация общих габаритов параллельных слоёв.

> Версия `0.4.0-beta` является предварительной. Перед применением результата проверьте размеры, расположение опор и конструктивные ограничения поддона.

## Возможности

- Ручной расчёт размеров и расположения брусьев по длине и ширине с контролем зазоров и геометрии.
- Построение поддона по STEP-модели оборудования и автоматически определённым опорам.
- Стандартные и пользовательские сечения бруса в формате **высота × ширина**, включая замену сечения одного или нескольких уже построенных брусьев.
- Округление габаритов: до 50 мм, вверх до кратного 5 мм или без округления.
- Интерактивная 3D-визуализация: изометрия, виды сверху/спереди/сбоку, вписать модель, размерные линии и скрытие/показ импортированной установки.
- Добавление внутренних брусьев через точки `+` с предпросмотром, удаление выбранных внутренних брусьев и редактирование расстояний.
- Сохранение и открытие проектов в формате `.palletlab.json`.
- Экспорт деталей и сборки в **SolidWorks** (`.SLDPRT`, `.SLDASM`) и **КОМПАС-3D** (`.m3d`, `.a3d`).
- Выбор папки экспорта: для каждого поддона создаётся отдельная подпапка с деталями и сборкой.
- Проверка обновлений установленной версии и установка с проверкой SHA-256.

## Построение по 3D-модели

1. Нажмите **«Построить по модели»** и выберите файл `.step` или `.stp`.
2. Дождитесь окончания загрузки. Во время импорта отображается модальное окно с прогрессом.
3. Нажмите на плоскую нижнюю грань любой опоры установки. Грань под курсором подсвечивается.
4. PalletLab найдёт опоры в той же плоскости, построит поддон и покажет найденные опорные грани.
5. При необходимости измените сечение бруса, отступы или правила округления — поддон будет перестроен по тем же опорам.
6. Нажмите **«Перестроить по модели»**, чтобы убрать только поддон и выбрать другую опорную грань. Импортированная модель останется в сцене.

Поля **«Габарит → первая опора»** и **«Последняя опора → габарит»** используются только при ручном расчёте. Для STEP-модели они скрыты, поскольку расстояния определяются по габаритам и опорам импортированной установки.

Поддерживаются плоские опорные грани. Они могут находиться не в глобальной плоскости XY: выбранная нижняя грань определяет ориентацию поддона. Если поддон не построен, выберите другую нижнюю грань опоры или проверьте модель на пересекающиеся и неплоские элементы.

### Кэш STEP-моделей

После первого успешного импорта PalletLab сохраняет подготовленную сетку и сведения о гранях в локальном кэше Windows:

```text
%LOCALAPPDATA%\PalletLab\step_cache
```

При повторной загрузке неизменённого файла используется кэш. Он безопасно пересоздаётся при изменении исходной STEP-модели или формата кэша; удалить эту папку можно, если требуется принудительно очистить кэш.

## Ручной расчёт и редактирование

1. Укажите сечение бруса, расстояния между центрами опор, расстояния от габарита до крайних опор и внешние отступы.
2. Выберите направление верхнего слоя и правило округления.
3. Результат пересчитывается автоматически после изменения параметров.
4. При необходимости используйте инструменты 3D-вида для добавления бруса, удаления внутренних брусьев, изменения расстояния или замены сечения выбранных брусьев. При смене высоты бруса нижнего слоя верхний слой автоматически поднимается до его верхней грани.
5. Нажмите «Сохранить», чтобы записать проект в `.palletlab.json`, или «Открыть», чтобы восстановить его.

## Установка

Для обычного использования скачайте `PalletLab-Setup-<версия>.exe` на странице [Releases](https://github.com/pntech-dev/PalletLab/releases) и запустите установщик. Он добавляет программу в меню «Пуск»; после установки обновления будут предлагаться автоматически.

`PalletLab-<версия>-Portable.zip` — переносимый вариант без установки. В нём встроенное обновление не используется: новую версию нужно скачать вручную.

Для CAD-экспорта на компьютере должна быть установлена соответствующая система — SolidWorks или КОМПАС-3D — с доступным COM API.

## Экспорт

Выберите **«Экспорт в КОМПАС»** или **«Экспорт в SolidWorks»**, затем укажите родительскую папку. Внутри неё будет создан отдельный каталог поддона с файлами деталей и сборки.

## Обновления

Установленная через Setup программа при запуске проверяет GitHub Releases. Если опубликована более новая версия, появляется окно **«Скачать и установить»**. После загрузки приложение закрывается, встроенный апдейтер заменяет файлы и предлагает открыть новую версию.

Релиз содержит архив `PalletLab-<версия>-update.zip` и файл `PalletLab-<версия>-update.zip.sha256`. Они создаются автоматически в CI.

## Запуск из исходников

Требуются Windows и Python 3.11+.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:PYTHONPATH = "src"
python src\main.py
```

Если PowerShell не разрешает активацию, запускайте `.\.venv\Scripts\python.exe` вместо `python`.

## Тесты

```powershell
$env:PYTHONPATH = "src"
.\.venv\Scripts\python.exe -m pytest -q
```

## Релизы для разработчиков

Версия определяется корневым файлом `VERSION` в формате `MAJOR.MINOR.PATCH` либо `MAJOR.MINOR.PATCH-beta`. Она используется в заголовке приложения, пакете PyInstaller, имени установщика и GitHub Release.

Push в `dev` запускает только тесты. После слияния `dev` в `main` GitHub Actions повторно запускает тесты, собирает приложение и публикует GitHub Release с тегом `v<версия>`. Версия с суффиксом `-beta` публикуется как prerelease, без суффикса — как стабильный релиз.

Перед публикацией увеличьте `VERSION`. Если релиз с этим тегом уже существует, workflow не перезаписывает его.

## Структура проекта

```text
src/
  main.py                         # точка входа
  palletlab/core/                 # расчёт, модели, сохранение, валидация
  palletlab/controllers/          # действия редактора и геометрия viewport
  palletlab/importers/            # импорт и обработка STEP-моделей
  palletlab/exporters/            # SolidWorks и КОМПАС-3D
  palletlab/ui/                   # интерфейс PyQt5 и обновления
  palletlab/visualization/        # PyVista + pyvistaqt viewport
  updater_main.py                 # отдельный процесс установки обновления
tests/                            # pytest
installer/                        # скрипт Inno Setup
```

Расчётное ядро не зависит от PyQt5 и PyVista: оно формирует модель поддона, которую используют редактор, экспортёры и тесты.
