# PalletLab

PalletLab — Windows-приложение для проектирования двухслойных деревянных поддонов под оборудование. Оно рассчитывает размещение брусьев, показывает модель в 3D и экспортирует результат в CAD.

## Возможности

- расчёт размеров и расположения брусьев по длине и ширине с контролем зазоров и геометрии;
- стандартные и пользовательские сечения бруса в формате **высота × ширина**;
- правила округления габаритов: производственное до 50 мм, вверх до кратного 5 мм или без округления;
- интерактивная 3D-модель: изометрия, виды сверху/спереди/сбоку, вписать модель и показ размерных линий;
- добавление внутренних брусьев через точки `+` с предпросмотром и удаление выбранных внутренних брусьев;
- сохранение и открытие проектов в формате `.palletlab.json`;
- экспорт деталей и сборки в **SolidWorks** (`.SLDPRT`, `.SLDASM`) и **КОМПАС-3D** (`.m3d`, `.a3d`);
- выбор папки экспорта: для каждого поддона создаётся отдельная подпапка с деталями и сборкой;
- проверка обновлений при запуске установленной версии и установка из приложения с проверкой SHA-256.

## Установка

Для обычного использования скачайте `PalletLab-Setup-<версия>.exe` на странице [Releases](https://github.com/pntech-dev/PalleteLab/releases) и запустите установщик. Установщик добавляет программу в меню «Пуск»; после установки обновления будут предлагаться автоматически.

`PalletLab-<версия>-Portable.zip` — переносимый вариант без установки. Он не предназначен для встроенного обновления: новую версию в этом случае нужно скачать вручную.

Для CAD-экспорта на компьютере должна быть установлена соответствующая система — SolidWorks или КОМПАС-3D — с доступным COM API.

## Работа с проектом

1. Укажите исходные параметры и выполните расчёт.
2. При необходимости скорректируйте внутренние брусья в 3D-виде.
3. Нажмите «Сохранить», чтобы записать проект в `.palletlab.json`, или «Открыть», чтобы восстановить сохранённый проект.
4. Для CAD-экспорта выберите «Экспорт в КОМПАС» либо «Экспорт в SolidWorks», затем укажите родительскую папку. Внутри неё будет создан каталог поддона с файлами деталей и сборки.

## Обновления

Установленная через Setup программа после запуска проверяет GitHub Releases. Если опубликована более новая версия, появляется окно с кнопкой «Скачать и установить». После загрузки приложение закрывается, встроенный апдейтер заменяет файлы и предлагает открыть новую версию.

Релиз должен содержать архив `PalletLab-<версия>-update.zip` и файл `PalletLab-<версия>-update.zip.sha256`. Оба файла создаются автоматически в CI.

## Запуск из исходников

Требуются Windows и Python 3.11+.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:PYTHONPATH = "src"
python src\main.py
```

Если PowerShell не разрешает активацию, запускайте `.\.venv\Scripts\python.exe` вместо `python`.

## Тесты

```powershell
$env:PYTHONPATH = "src"
.\.venv\Scripts\python.exe -m pytest -q
```

## Релизы для разработчиков

Версия определяется корневым файлом `VERSION` в формате `MAJOR.MINOR.PATCH` либо `MAJOR.MINOR.PATCH-beta`. Push в `main` запускает GitHub Actions: тесты, сборку приложения и апдейтера, создание Setup, portable-архива, update-архива с контрольной суммой и GitHub Release с тегом `v<версия>`. Версии с суффиксом `-beta` публикуются как prerelease.

Перед публикацией новой версии увеличьте `VERSION`. Если релиз с этим тегом уже существует, workflow не перезаписывает его.

## Структура проекта

```text
src/
  main.py                         # точка входа
  palletlab/core/                 # расчёт, модели, сохранение, валидация
  palletlab/controllers/          # действия редактора и геометрия viewport
  palletlab/exporters/            # SolidWorks и КОМПАС-3D
  palletlab/ui/                   # интерфейс PyQt5 и обновления
  palletlab/visualization/        # PyVista + pyvistaqt viewport
  updater_main.py                 # отдельный процесс установки обновления
tests/                            # pytest
installer/                        # скрипт Inno Setup
```

Расчётное ядро не зависит от PyQt5 и PyVista: оно формирует модель поддона, которую используют редактор, экспортёры и тесты.
