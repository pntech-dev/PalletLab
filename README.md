# PalletLab

PalletLab — Windows desktop-приложение для расчёта расположения деревянных брусьев под оборудованием и интерактивной 3D-визуализации двухслойного поддона.

## Возможности первой версии

- независимый расчёт по длине и ширине по центрам опор;
- стандартные сечения и пользовательское сечение в формате **высота × ширина**;
- корректные крайние брусья, полностью расположенные внутри габарита поддона;
- выбор округления габарита поддона: до 50 мм по производственному порогу 10 мм, вверх до кратного 5 мм или без округления;
- проверка чистых зазоров и физической геометрии;
- двухслойная 3D-модель из реальных параллелепипедов PyVista;
- переключение верхнего слоя и камера: изометрия, сверху, спереди, сбоку, вписать модель.
- интерактивная вставка бруса через точки `+` в доступных промежутках с предпросмотром, вводом зазора и подтверждением Enter.

В этой версии намеренно нет CAD/STEP-экспорта, базы данных, материалов, проектов, авторизации или расчёта прочности.

## Установка

Требуется Windows и Python 3.11+.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Если PowerShell не разрешает активацию, можно не активировать окружение и выполнять `.\.venv\Scripts\python.exe` вместо `python` во всех командах ниже.

## Запуск

```powershell
$env:PYTHONPATH = "src"
.\.venv\Scripts\python.exe src\main.py
```

Главное окно открывается с проверочным примером: поддон `4205 × 1940 × 140 мм` (с включённым округлением), 7 брусьев в одной группе и 5 в другой.

## Тесты

```powershell
$env:PYTHONPATH = "src"
.\.venv\Scripts\python.exe -m pytest -q
```

## Будущая сборка через PyInstaller

PyInstaller и поддерживаемый файл `palletlab.spec` уже подготовлены. Когда потребуется создать `.exe`, из активированного окружения выполните:

```powershell
pyinstaller palletlab.spec
```

Эта команда намеренно **не выполнялась** при создании проекта: в репозитории нет `build/`, `dist/` или готового `.exe`.

## Структура

```text
src/
  main.py                         # точка входа
  palletlab/core/                 # чистая математика, модели, валидация
  palletlab/ui/                   # PyQt5 формы и результаты
  palletlab/visualization/        # PyVista + pyvistaqt viewport
tests/                            # pytest для геометрического ядра
```

`core` не импортирует PyQt5 или PyVista. Он возвращает структурированные результаты, из которых слой визуализации строит каждую 3D-балку без самостоятельного перерасчёта координат.
