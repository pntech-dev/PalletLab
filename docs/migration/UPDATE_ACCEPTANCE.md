# Проверка обновлений установленной версии

## Изолированная проверка без публикации

Команда `.venv/Scripts/python.exe tests/run_update_e2e.py` создаёт тестовую
копию в `build/update-e2e`, локальный сервер и архив с версией `9.9.9`.
Тестовая сборка использует отдельный runtime hook: только сетевой транспорт
направляется на `127.0.0.1`, вместо обычного диалога сохранения выбирается
тестовый путь, а команды интерфейса выполняются автоматически. Код обнаружения,
проверки SHA-256 и запуска настоящего апдейтера остаётся тем же. Рабочая
установка и релизы GitHub не изменяются. Среда должна разрешать подключения
встроенного браузера к loopback.

До прогона нужны production-сборки приложения и апдейтера в
`build/update-check` и helper в `build/SolidWorksDrawingHelper`. Тест строит
отдельный экземпляр, сохраняет проект, проверяет запрет установки до сохранения
и заменяет файлы только в нём. Проверка неправильной контрольной суммы и
восстановления файлов после ошибки выполняется тестами pytest.

Выполнено локально 09.11.2026: тест прошёл обнаружение версии, скачивание,
SHA-256, сохранение проекта, запуск апдейтера и замену исполняемого файла и
версии. Обновлённая тестовая копия прошла `--smoke-test`. Прогон не проверяет
сетевой путь до GitHub, настоящий Setup и работу на чистой машине.

## Проверка поставки

Проверять на отдельной тестовой Windows-машине с установленной тестовой версией
и опубликованным тестовым релизом. Укажите дату, версии Windows и приложения,
версию тестового релиза и способ установки. Используйте тестовые проекты и
отдельную тестовую установку; проверка заменяет файлы этой установки.

1. Запустите установленную версию, когда доступна новая: должно появиться окно
   с номером версии. «Позже» закрывает окно, а кнопка в шапке открывает его снова.
2. Измените проект и скачайте обновление. До установки сохраните проект: кнопка
   установки недоступна, пока есть несохранённые изменения.
3. Установите обновление, откройте приложение из окна апдейтера и проверьте
   версию, открытие сохранённого проекта, STEP и CAD.
4. Повторите проверку при отключённой сети и при повреждённом тестовом архиве:
   приложение остаётся работоспособным, неподтверждённый пакет не запускается.
5. Запустите portable-копию и исходную версию: автоматического предложения
   обновиться быть не должно. Повторите обновление на прежней установленной
   версии без файла-маркера, но с штатным деинсталлятором и папкой Updater.
6. Проверку сбоев установки и восстановления файлов выполняйте только на
   копии тестовой установки. Проверьте, что старые файлы восстанавливаются.

Текущие автоматические тесты не подтверждают работу Windows-интерфейса установки
или доступность настоящего релиза; эти пункты закрываются ручным протоколом.
