# Живой чек-лист приёмки миграции

Этот документ фиксирует обязательный функциональный паритет между текущей
версией на PyQt5/PyVista и новой реализацией на React/pywebview/Three.js.
Пункт считается перенесённым только после автоматической проверки там, где она
возможна, и ручной проверки на Windows для интерактивных либо CAD-сценариев.

## Обозначения и правило заполнения

| Статус | Значение |
| --- | --- |
| ✅ | Подтверждено: указан тест либо ручной протокол с датой и средой. |
| 🟡 | Реализовано в коде, но ещё требует ручной либо внешней проверки. |
| ⬜ | Не проверялось или работа не начата. |
| ❌ | Обнаружен блокер; в результате должна быть ссылка на issue, лог или коммит исправления. |

Для каждой ручной проверки в колонке «Подтверждение» записываются: дата,
версия Windows и масштаб DPI, версия CAD (если применимо), файл проекта или
STEP-модель и итог. Скриншоты, логи и файлы-образцы хранятся или связываются
в соответствии с правилами проекта.

Первый ручной прогон React viewport, проекта и STEP выполняется по
[`MIGRATION_VIEWPORT_STEP_PROTOCOL.md`](MIGRATION_VIEWPORT_STEP_PROTOCOL.md).

## Локальная проверка поставки — 9 ноября 2026

На Windows build 26200 в рабочем дереве после `b7d8d05` собраны тестовые
installer, portable и update ZIP. Полный набор: 230 Python-тестов, frontend
build и три frontend-теста прошли; Ruff и mypy прошли. Portable и update ZIP,
созданные через `Compress-Archive` как в CI, проверены по содержимому и CRC;
SHA-256 update ZIP совпал. Извлечённая portable-копия прошла `--smoke-test` и
импорт сгенерированного STEP в отдельном воркере.

Установщик собран с Inno Setup 6.7.4. Для безопасного локального прогона
отдельно собрана тестовая вариация сценария с другим AppId, без деинсталлятора,
ярлыков и автозапуска; остальные файлы и раскладка сохранены. Установка в
папку проекта завершилась успешно. Маркер установленной версии, приложение и
апдейтер на месте, установленная копия прошла smoke-test и STEP, а входящий в
неё SolidWorks helper успешно запустился в режиме проверки аргументов.
Полный update ZIP, созданный как в CI, затем установлен настоящим апдейтером
в эту изолированную копию: версия и исполняемый файл обновились, маркер остался,
повторные smoke-test и импорт STEP прошли.

Это не проверка неизменённого установщика на чистой Windows: установку,
удаление, обновление и открытие реальных проектов и CAD-файлов в обоих каналах
по-прежнему нужно подтвердить вручную на отдельной машине. Реальная установка
пользователя при локальном прогоне не затрагивалась.

## Правило финальной приёмки

Удаление PyQt5/PyVista и выпуск новой версии разрешены только когда все строки,
для которых требуется ручная или внешняя проверка, переведены в `✅` либо имеют
принятое документированное исключение. Новый Figma-дизайн проверяется повторным
проходом той же матрицы: визуальные изменения не отменяют ни одного
функционального требования.
